الـ Systems Analyst 🧑‍💻

مش مبرمج! هو المترجم بين عالمين. اضغط على كل طرف وشوف.

⇄
⇄
UsersManagersSteering committee

بيتكلموا لغة الـ business: revenue, market share, ROI.

شغله 3 حاجات:

  1. Analyze the business situation — يحلل الوضع الحالي
  2. Identify opportunities for improvements — يلاقي فرص التحسين
  3. Design an information system to implement the improvements — يصمم نظام ينفذها

وكمان بيتعامل مع ناس تانية: vendors و consultants.

DBAsNetwork adminsProgrammers

بيتكلموا لغة التقنية: databases, APIs, network.

الفرق اللي بيتسأل عليه كتير: Analysis ضد Design

SDLC ⭐

أهم حاجة في المحاضرة. 4 phases — اضغط على كل واحدة. احفظهم P · A · D · I

Why → What → How → Do it

Why?ليه نبني النظام؟ وهندير المشروع إزاي؟
  1. Project Initiation — الـ sponsor يكتب System Request + بنعمل preliminary feasibility analysis (المشروع يستاهل ولا لأ؟)
  2. Set up the project — بنعمل Project Plan = work plan + staffing plan
📦 Deliverables: System RequestFeasibility StudyProject Plan
📖 من الكتاب: بعد ما الـ steering committee يوافق، الـ project manager بيجهّز الخطة التفصيلية.
What · Who · Where · Whenالنظام لازم يعمل إيه؟ ومين هيستخدمه؟ وفين وإمتى؟
  1. Determine analysis strategy — ندرس النظام الحالي (As-Is) ومشاكله
  2. Collect & analyze requirements — نتخيل النظام الجديد (To-Be) ونوصفه بـ analysis models
  3. Prepare & present the System Proposal — نلخّص نتيجة الـ Analysis
📦 Deliverable: System Proposal
🚦 Go / No-Go decision — الـ sponsor والـ steering committee يقرروا يكمّلوا ولا لأ.
How?النظام هيتبني ويشتغل إزاي؟
  1. Determine design strategy — BuildBuyOutsource
  2. Design system components — architecture, interface, database, programs وبعدين نجمعهم في System Specification
  3. Present to steering committee — نأخد قرار قبل المرحلة الأخيرة
📦 Deliverable: System Specification
🚦 Go / No-Go decision قبل ما ندخل الـ Implementation.
Do itنبني ونسلّم ونشغّل
  1. System Construction — Programming and testing
  2. System Installation — Training + Conversion للنظام الجديد
  3. On-going system support — دعم وصيانة بعد التشغيل
📦 Deliverable: Installed, working system
🔁 ده الشكل النظري (ورا بعض). في الواقع الـ phases بتتداخل وبنرجع نعدّل في اللي قبلها — يعني الـ SDLC iterative.

📖 من الكتاب — بيتسأل في الـ Assessment بتاع Ch1:

Logical process model

بيوصف WHAT: العملية بتعمل إيه، من غير أي تكنولوجيا. بيناسب الـ Analysis.

Physical process model

بيوصف HOW: هتتنفذ إزاي، وبيبيّن الـ hardware والـ files والـ code. بيناسب الـ Design.

شرحهم الكامل في الكتاب جاي في Ch8، بس السؤال بتاعهم موجود في Ch1.

المشاريع بتيجي منين؟ 🌱

أي مشروع نظام بيبدأ من business need. دي الأسباب:

🎯 Enable a business initiative / strategy 🤝 Support a merger / acquisition 🩹 Fix a "point of pain" 🆕 Utilize a new technology 🔁 Outgrowth of BPM

BPM — Business Process Management

منهج بتستخدمه الشركات عشان تحسّن الـ end-to-end business processes باستمرار. بيمشي في 4 خطوات (دايرة بتتكرر):

1
Define & map
نرسم خطوات الـ process
2
Improve
نحسّن الخطوات اللي بتضيف value
3
Eliminate
نشيل أو ندمج الخطوات اللي مش بتضيف value
4
Adjust workflows
نعدّل الـ electronic workflows على الشكل الجديد

🔁 وبعدين نرجع للخطوة 1 — مستمرة (continuous)

فوايده: Enhanced process agilityAlignment with industry best practicesIncreased process efficiencies
